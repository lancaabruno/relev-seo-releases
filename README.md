# Relev SEO — Downloads para Windows

Canal público de instaladores e atualizações do Relev SEO para Windows 64 bits (Intel/AMD).

## Instalar

Quando uma versão estiver publicada, baixe o arquivo `Windows-x64-Setup.exe` em [Releases](https://github.com/lancaabruno/relev-seo-releases/releases).

Nas versões com atualizador integrado, o aplicativo consulta este canal, baixa novas versões em segundo plano e oferece **Reiniciar e atualizar**. A instalação aguarda a conclusão das operações e cria um backup antes de reiniciar.

Quem usa a versão 1.4.0 ou anterior precisa instalar manualmente uma versão com atualizador uma vez. As próximas podem ser recebidas pelo próprio aplicativo.

Os arquivos `.sha256` permitem conferir os downloads. `latest.yml` e `.blockmap` são utilizados pelo atualizador.

Este repositório contém somente documentação de distribuição, instaladores e metadados. O repositório de desenvolvimento permanece privado. Os dados dos clientes ficam no computador de cada usuário e não são enviados para este repositório.
